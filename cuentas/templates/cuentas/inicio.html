El problema

Muchas clínicas veterinarias todavía trabajan con papel, llamadas y hojas sueltas. Eso significa desorden, tiempo perdido y tutores que no saben qué le toca a su mascota. Woof lo reúne todo en un solo lugar.

{# ================= Cómo se construye ================= #}

Cómo se construye

Hecho como un proyecto profesional.

Woof sigue la arquitectura MVC de Django: cada petición recorre el mismo camino, de la URL a la base de datos y de vuelta a tu pantalla.

{# Recorrido de una petición en Django (MTV) #}
  1. Navegador
  2. URLs
  3. VistaControlador
  4. ModeloORM → Neon
  5. PlantillaHTML

Django 5.2

Framework de Python con el patrón MVC (MTV), su ORM y plantillas HTML.

PostgreSQL en Neon

Base de datos en la nube, con reglas de integridad también en SQL.

Doble factor

Inicio de sesión con contraseña y un código de verificación con Twilio.

Git y Pull Requests

Cada tarea en su rama, revisión del compañero y Conventional Commits.

Integración continua

GitHub Actions corre las pruebas automáticas en cada Pull Request.

Bootstrap y Three.js

Interfaz adaptable a celular y animación 3D liviana en la portada.
